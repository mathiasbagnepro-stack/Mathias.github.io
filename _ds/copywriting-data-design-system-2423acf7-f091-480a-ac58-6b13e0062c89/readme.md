## Contexte produit

**Copywriting Data** est une activité de copywriting freelance fondée par un ancien ingénieur (génie chimique, Technip Energies, Arkema). La marque fournit des services de copywriting aux infopreneurs et créateurs de formations francophones — principalement ceux dont les revenus dépendent des lancements.

**Positionnement différenciant :** Le copywriting traité comme une discipline d'ingénierie. Là où les autres copywriters vendent du talent et des résultats anecdotiques, Copywriting Data vend une méthode reproductible et auditable.

**Méthode propriétaire :** Analytics email comportemental + analyse psychographique IA des appels clients = copy auditable et optimisé.

**Cibles :** Infopreneurs et créateurs de formations francophones. Niches confirmées : DJ training, coaching business/wellness, rénovation, thérapie somatique, praticiens bien-être.

**Produits / surfaces :**

- Site web de présentation + réservation (page pro pour réserver une consultation)
- Posts réseaux sociaux (LinkedIn analytique, Instagram visuel/narratif)
- Rapports de livraison client
- Présentations / slides

## CONTENT FUNDAMENTALS

### Langue

Français exclusivement. Vocabulaire d'ingénieur assumé et recherché.

### Ton de voix

- **Analytique sans être froid.** Direct sans être brutal.
- Parle comme un ingénieur qui aurait appris à vendre : explique le mécanisme, puis montre que le mécanisme marche.
- Confiance tranquille de quelqu'un qui a les chiffres.
- Ne flatte pas — prouve.

### Structure des phrases

- Phrases courtes quand l'idée est tranchée.
- Phrases plus longues quand elle se construit (avec une logique interne explicite).
- Pas de point d'exclamation, sauf rareté calculée.
- Zéro politesse de remplissage ("J'espère que ce message vous trouve en bonne santé" → supprimé).

### Règle de densité

Si une phrase peut sauter sans perte d'information, elle saute.

### Perspective

- `Je` pour les communications personnelles (réseaux sociaux, bio, page pro).
- `La méthode` / `Copywriting Data` pour les supports produit formels.

### Casse

- `COPYWRITING DATA` (les deux mots, toujours capitalisés dans l'identité visuelle)
- Titres H1 : CAPITALES
- Corps de texte : sentence case standard
- Pas de casse décorative dans les paragraphes

### Ponctuation

- Pas de `!` sauf usage calculé (max 1 par support)
- Tirets longs `—` pour les incises
- Points finaux sur les phrases complètes dans les slides et rapports

### Émojis

**Aucun emoji** dans les supports formels (site, rapports, slides). Peut apparaître avec parcimonie sur Instagram dans les posts narratifs. Jamais sur LinkedIn.

### Lexique propriétaire (à employer et répéter)

| Terme | Usage |
| --- | --- |
| Copywriting Data | La méthode nommée — toujours avec majuscules |
| Analyse psychographique | Méthode d'analyse des appels clients par IA |
| Signal sur bruit | Métaphore centrale de la marque |
| Variable de conversion | Élément isolé et mesuré |
| Itération mesurée | Cycle d'amélioration basé sur les données |
| Le copy auditable | Résultat livrable — on peut retracer le raisonnement |
| Avatar data-driven | Portrait client construit par les données |

### À bannir absolument

- « Des mots qui vendent »
- « Le pouvoir des mots »
- « En tant que copywriter passionné »
- Toute formule copywriting générique non différenciante

### Exemples de copy conforme

**Baseline :** Le copy qui se mesure.

**Pitch court :** Ex-ingénieur devenu copywriter. Je ne devine pas ce qui convertit, je le mesure. Méthode Copywriting Data : analytics comportemental + analyse psychographique des appels clients.

**Section différenciation :** Le copywriter standard vous montre un texte. Copywriting Data vous montre le raisonnement, les données sources, et la logique de décision. Ce n'est pas plus ambitieux — c'est juste auditable.

## VISUAL FOUNDATIONS

### Concept directeur

**Nocturne premium.** Un univers sombre, dense, haut de gamme. L'orange tangerine agit comme signal — métaphore visuelle du positionnement : extraire le signal du bruit. Le fond noir/bleu nuit est le bruit ambiant ; l'orange est la donnée qui ressort.

Inspiration objet : l'instrument de précision (le stylo plume de luxe), pas le gadget tech.

### Couleurs

| Nom | HEX | Rôle |
| --- | --- | --- |
| Deep Black | `#0B0B0B` | Fond principal, base de tout support sombre |
| Midnight Blue | `#050A1B` | Fond secondaire, profondeur, dégradés |
| Tangerine | `#FF5C02` | Accent unique, CTA, signal, mise en valeur data |
| Cream | `#FEFAE1` | Texte sur fond sombre, fonds clairs, respiration |

**Règle d'or :** L'orange ne dépasse jamais \~10% de la surface d'un support. C'est ce qui lui donne sa valeur de signal. Multiplier l'orange détruit le concept.

**Hiérarchie des fonds :** Noir profond par défaut → Bleu minuit pour les seconds plans → dégradés noir→bleu. Le crème pour les zones de respiration et les supports print.

### Typographie

**Système à deux familles principales :**

- **Titres :** Rajdhani (sans-serif technique, bold, caps). Police du logo — identité visuelle cohérente. Tracking modéré (0.10–0.14em), poids 600–700. Évoque la précision, la donnée, l'ingénierie.
- **Corps et UI :** Manrope (sans-serif géométrique, neutre, très lisible). Porte le corps de texte, les labels, les métriques secondaires.
- **Serif optionnel :** Cormorant Garamond — conservé pour les italiques d'accroche, sous-titres délicats, supports print premium.
- **Monospace (data accent) :** JetBrains Mono. Réservée aux chiffres clés, labels techniques, snippets de métriques.

**Hiérarchie type :**

- H1 : Rajdhani 700, CAPITALES, crème, tracking +12%
- H2 : Rajdhani 600, CAPITALES, crème ou orange, tracking +10%
- H3 : Rajdhani 600, CAPITALES, crème, tracking +10%
- Corps : Manrope regular, crème à 90% d'opacité
- Données clés : JetBrains Mono bold, tangerine

### Backgrounds et surfaces

- Dark mode natif sur tous les supports numériques.
- Fond primaire : `#0B0B0B` (Deep Black)
- Fond secondaire : `#050A1B` (Midnight Blue)
- Cards : `#121A34` avec `1px solid rgba(254,250,225,0.15)`
- Dégradé signature (hero, couvertures) : noir profond → bleu minuit vertical, touche d'orange en bas
- Jamais de fonds colorés vifs autres que l'orange en accent ponctuel
- Print/rapport imprimable : fond crème, texte noir profond, accents orange

### Espacement et négatif

- L'espace négatif est un actif, pas un vide à remplir.
- Sections : `padding: 6rem` vertical minimum
- Cards : `padding: 2rem`
- Densité : une seule idée par slide, une seule CTA par section

### Coins et bordures

- Border radius très conservateur : `2px` (sm), `4px` (md), `8px` (lg)
- Jamais de radius >12px sauf pills (tags, badges)
- Bordures : `1px solid rgba(254,250,225,0.15)` sur les cards
- Jamais de border-left colorée seule comme décoration

### Ombres

- Ombres sombres (foncées sur fond déjà sombre) : `box-shadow: 0 4px 16px rgba(0,0,0,0.4)`
- Glow tangerine pour les états focus et CTA primaire : `0 0 20px rgba(255,92,2,0.25)`
- Inner shadow subtil sur les cards : `inset 0 1px 0 rgba(254,250,225,0.06)`

### Animations et transitions

- **Durée :** 150ms (micro-interactions), 200ms (transitions d'état), 350ms (entrées de contenu), 500ms (révélations hero)
- **Easing :** `ease` standard. `cubic-bezier(0.16, 1, 0.3, 1)` pour les révélations (ease-out élastique léger)
- Pas d'animations infinies décoratives sur le contenu
- Pas de bounce — la marque est précise, pas joueuse
- Fade + translate-Y pour les entrées (déplacement de haut en bas, léger)

### États hover et press

- **Hover bouton primaire :** `#E65200` (tangerine plus foncé) + subtle glow
- **Hover lien :** opacity de `0.7` → `1.0`
- **Hover card :** border passe à `rgba(255,92,2,0.35)`, légère montée `translateY(-2px)`
- **Press / active :** `#CC4900` + léger scale `0.98`
- Pas de soulignement sur les liens de navigation (underline seulement dans le corps de texte)

### Imagerie

- Registre premium : objet, matière, lumière contrôlée sur fond sombre.
- Macro d'instruments de précision, textures (cuir, papier, métal brossé)
- Éviter : photos d'agence génériques, personnes souriantes devant un ordinateur
- Data visualisation : fonds sombres, courbes/barres crème, point clé en orange
- Traitement couleur : sombre, contrasté, avec orange comme seul point de couleur

### Data visualisation

Un actif de marque à part entière.

- Fond : `#121A34` ou `#0B0B0B`
- Axes et grille : `rgba(254,250,225,0.15)`
- Série principale : crème
- Point/valeur clé : orange tangerine
- Labels : Manrope ou JetBrains Mono, crème 70%

### Ponctuation visuelle

- Le losange `◆` crème est la signature visuelle de bas de slide, séparateur, et marque de fin
- Ligne fine orange pour encadrer "DATA" dans certains titres (`— DATA —`)
- Jamais d'emoji, jamais d'icônes pleines et colorées

### Grille de mise en page

- Max-width : 1200px (contenu), 1440px (wide)
- Colonnes : CSS Grid, gutters de 2rem
- Sections hero : full-width, full-bleed
- Navigation : fixe, fond `rgba(11,11,11,0.92)` + backdrop-blur

## ICONOGRAPHY

### Approche générale

Style **linéaire fin** (stroke, pas fill). Crème ou tangerine, jamais d'icônes pleines colorées. Cohérence avec la finesse typographique de la marque.

### Système recommandé

**Lucide Icons** (CDN disponible) — stroke weight 1.5px, style linéaire épuré. Correspond parfaitement à l'esthétique de la marque.

Usage CDN : `https://unpkg.com/lucide@latest/dist/umd/lucide.js`

Les icônes utilisées dans ce design system sont référencées par leur nom Lucide.

### Icônes clés de la marque

| Icône | Lucide name | Usage |
| --- | --- | --- |
| Graphique données | `bar-chart-2` | Métaphore centrale, slide data |
| Tendance | `trending-up` | Performance, résultats |
| Cible | `target` | Objectif, conversion |
| Engrenage | `settings-2` | Méthode, système |
| Loupe data | `search` | Analyse, recherche |
| Enveloppe | `mail` | Email analytics |
| Téléphone | `phone` | Analyse des appels |
| Calibrage | `sliders` | Variable, itération |
| Losange | `diamond` | Signature de marque |

### Emoji

Aucun dans les supports formels. Usage très limité sur Instagram.

### Logo

Wordmark + monogramme. Voir `assets/logo-dark.png`.

- Logo principal : "COPYWRITING" serif crème + "DATA" tangerine, encadré de lignes fines
- Icône associée : stylo plume (or/luxe) + graphique en barres (orange) + courbe de tendance
- Monogramme `CD` ou point/curseur orange pour favicon et avatar réseaux
